# Trend Atlas · 全球趋势雷达

可运行的个人趋势阅读网站。地区、12个方向、平台多选、搜索、时间筛选、列表/卡片、原始名次与历史、来源详情、本机收藏和视图、CSV导出、自动刷新与健康状态。

## 访问与本地启动

正式网址由 Sites 发布，默认仅拥有者可访问。Windows 在本目录双击 `start.cmd`，或执行 `./run-site.ps1`，地址为 http://127.0.0.1:4188/ 。关闭终端或 Ctrl+C 停止。

要求 Node.js >=22.13（推荐24）和 npm。依赖已在本次工作区安装；复制源代码到其他机器后先 `npm ci`。首次本地启动会生成构建并应用尚未执行的本地迁移。Windows 脚本可复用 Codex 已安装的兼容运行时及系统代理；生产配置不包含本机代理。

开发：`npm run dev`（默认5173，若系统保留该端口可 `node scripts/run-framework.mjs dev --port 4187`）。构建：`npm run build`。核心测试：`node scripts/test-core.mjs`。类型检查：`npx tsc --noEmit`。

## 配置

可从 `.env.example` 建立本地 `.env`。`YOUTUBE_API_KEY` 启用美国 YouTube 官方热门视频。`UAPI_KEY` 使用 Bearer 认证，扩大剩余国内来源的可用额度；没有密钥也能使用公开/社区源，状态会明确显示。发布环境变量须通过 Sites 配置，禁止将密钥写入代码或提交 Git。

平台与主题配置：`lib/catalog.ts`；采集适配器：`lib/adapters.ts`；持久缓存、锁与配额：`lib/feed.ts`；分类规则：`lib/classify.ts`；筛选去重导出：`lib/explore.ts`；结构校验：`lib/validate.ts`；界面：`components/trend-app.tsx`；样式：`app/atlas.css`。

## 当前来源

配置30个来源。国内含小红书、微博、抖音、知乎、百度、B站、头条、IT之家、36氪、掘金；国际含Hacker News、DEV、GitHub Trending、Reddit与各地区/方向新闻RSS。X、TikTok、Instagram为明确标注的平台入口；YouTube需配置密钥。Github/Reddit可能被公开接口访问策略阻断，不保证可用。成功内容不包含演示数据；测试中的合成fixture只在tests内。

地区按来源市场/新闻版面标注。欧洲当前为英国版。中文界面保留原语言标题与署名，未做模型翻译或未经核验的摘要。分类按关键词规则且可本机修正。位置分仅表示来源样本内名次，不是全网热度。

多数学源10分钟共享缓存，UAPI访客模式6小时，并有每日40次/月1200次的应用侧保护。失败退避，最多保留24小时；旧缓存标明且降低排序优先级。网站按访问采集，未访问时不后台轮询。收藏、视图与分类修正仅在当前浏览器。

本站默认个人、非商业用途和私有访问。Google News RSS用于个人阅读器；公开/商业发布前需要更换来源或取得许可。来源内容属于原作者，不提供金融买卖指令。

## 验证与后续维护

核心自动测试覆盖安全URL、HTML清理、分类、时间、源榜名次、去重、CSV公式防护、损坏缓存/本机数据、D1兼容SQLite查询、刷新去重、持久缓存、名次历史、失败回退、24小时过期与锁释放。浏览器验收覆盖真实来源与主要交互以及320/390px手机布局。

运行边界、代理分工、实际提示词及中断恢复步骤见 `WORKFLOW.md`。网站运行与编程代理的5小时额度无关；当前环境没有额度恢复调度接口，未宣称已经配置自动唤醒。
